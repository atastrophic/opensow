Use this tool to suggest switching to the research agent when the user's request would benefit from deep research before implementation.

If they explicitly mention wanting to research a topic ALWAYS call this tool first.

This tool will ask the user if they want to switch to the research agent.

Call this tool when:
- The user's request is complex and would benefit from research first
- You want to investigate and gather information before making changes
- The task involves exploring multiple sources or understanding a topic in depth

Do NOT call this tool:
- For simple, straightforward tasks
- When the user explicitly wants immediate implementation
